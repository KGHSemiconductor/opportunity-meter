# 기회비용 미터 (Opportunity Meter)

지금 이 순간에도 쌓이는 돈을 **1초 단위**로 보여주는 Windows 데스크톱 공부 위젯입니다.

- **취업 준비:** 목표 회사 두 곳에 다녔다면 받았을 연봉 + 성과급이 하루 종일 1초씩 쌓입니다.
- **직장인:** 근무 시간에만 내 월급이 쌓이고, 이직 목표 회사와의 연봉 차액도 보여줍니다.

공부 / 휴식 / 딴짓을 기록하고, 딴짓하면 위젯이 빨갛게 깜빡이며 흔들립니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 실시간 금액 카운터 | 두 줄 카운터, 7초마다 바뀌는 한 줄 정보 (놓친 돈 = 치킨 87마리, 월급날 D-18 등) |
| 공부 기록 | 공부 · 휴식 · 딴짓 버튼, 뽀모도로 (25 / 35 / 45 / 55분), 하루 목표 막대 |
| 알림 | 무작위 공부 체크인, 딴짓 경고, 멈춤 알림, 목표 달성, 밤 11시 오늘 결산 |
| 딴짓 경고 모드 | 빨간 화면 + 천천히 깜빡임 + 흔들림, 투명도·숨기기 설정 무시 |
| 공부 활동 | 켜진 시간 대비 공부 비율 — 일별 히트맵 · 주간 막대 · 누적 그래프 |
| 설정 창 | 사용 방식, 회사 · 연봉 · 성과급 계산기, 근무 시간, 목표, D-day, 오늘 기록 고치기 |

## 실행

**Python이 있는 경우** (Python 3.10 이상, 표준 라이브러리만 사용)

```
pythonw opportunity_meter.pyw
```

**exe로 만들기** (Python 없는 사람에게 배포할 때)

```
pip install pyinstaller
pyinstaller --onefile --noconsole --name OpportunityMeter opportunity_meter.pyw
```

`dist\OpportunityMeter.exe` 하나만 배포하면 됩니다. 서명되지 않은 exe라 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다 (추가 정보 → 실행).

## 사용법

| 동작 | 결과 |
|---|---|
| `▶ 공부` / `휴식` / `딴짓` 버튼 | 지금 상태 기록 |
| 더블클릭 | 공부 ↔ 딴짓 전환 |
| 드래그 | 위치 이동 |
| 오른쪽 위 `–` / `+` | 작게 보기 / 크게 보기 (같은 자리에서 전환) |
| 우클릭 | 전체 메뉴 (기록 멈춤, 설정, 공부 활동, 알림 등) |

처음 실행하면 우클릭 → **숫자 · 목표 설정**에서 내 상황(취업 준비 / 직장인)과 회사 · 연봉을 바꾸세요.

## 데이터

- 설정과 기록은 `%APPDATA%\OpportunityMeter\`에만 저장됩니다 (`config.json`, `today.json`, `history.json`).
- "켜진 시간"은 위젯이 켜져 있던 시간입니다 (절전 · 잠자기 제외).
- 금액은 입력한 숫자로 단순 계산한 값이며 실제 수령액과 다릅니다. 기본값(삼성 메모리 성과급 7.5억, SK하이닉스 영업이익 260조 × 10%)은 2026년 10월 보도 기준 추정치입니다.
